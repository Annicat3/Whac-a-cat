Whac-a-Cat

A simple Whac-a-Mole style browser game made with HTML, CSS, and JavaScript.

Click the cats as fast as possible before the timer runs out and try to get the highest score!

Features
* Two different cat sprites
* Score counter
* Timer
* Start button
* Play Again button

Built With
* HTML
* CSS
* JavaScript

This was my first game project and a way to learn web development basics.
